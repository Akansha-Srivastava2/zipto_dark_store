🚚 Zipto – Dark Store Data Analysis

📌 Project Overview

Zipto – Dark Store Data Analysis is an end-to-end data analytics project focused on evaluating the performance of dark store operations.

The project analyzes different aspects of dark store data, including product performance, sales, revenue, cost, profit, delivery operations, delivery partners, cancellations, returns, and delivery delays.

The analysis was performed using SQL and Microsoft Excel to transform raw data into meaningful business insights and identify areas where operational performance can be improved.




---

🎯 Project Objective

The main objective of this project is to understand the overall performance of Zipto's dark store operations and answer important business questions such as:

Which products are generating higher revenue and profit?

Which dark stores are performing better?

How much revenue, cost, and profit are being generated?

Which delivery partners have better delivery performance?

How many orders are delayed, cancelled, or returned?

What is the average delivery time?

How efficiently are orders being delivered?

Which areas require operational improvement?

📈 Dashboard

An Excel dashboard was created to provide a clear overview of sales, profitability, product performance, dark store performance, and delivery operations.

The dashboard allows users to analyze the data using different views and filters, making it easier to identify trends, operational issues, and performance differences across stores and delivery partners.

💡 Business Insights

The project helps identify:

Products contributing significantly to revenue and profit

Dark stores with comparatively better or weaker performance

Delivery partners with higher delivery delays

Trends in cancellations and returns

Areas affecting delivery efficiency

Relationship between operational performance and profitability


These insights can help businesses monitor dark store operations and make data-driven operational decisions.
